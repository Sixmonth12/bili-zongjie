# 知帧 · Bilibili 视频学习 App

本地网页 App：导入字幕 → 生成概要与精华 → 每轮一个问题 → 按回答反馈 → 保存掌握证据。
Python 3.10+，仅使用标准库，不用安装依赖。

界面使用蓝白玻璃主题。背景插画裁自用户提供的视觉参考图右侧，保存在 `static/reference-art.jpg`，并以内嵌图片形式用于样式；不是重新生成的插画。`static/glass-theme.css` 保存主题样式源稿，当前页面加载的完整样式为 `static/style.css`。顶部快捷入口对应添加视频、导入字幕、打开 B 站和演示学习。

## 启动

Windows 双击 `start.bat`，或在本目录运行：

```powershell
python server.py --open
```

浏览器访问 
bili-zongjie.pages.dev。关闭终端会停止服务。端口占用时可运行 `python server.py --port 8766 --open`。

## 使用

顶部「修改资料」支持编辑当前会话的字幕副本或材料草稿、导入文件、下载修改后的 TXT/SRT/VTT/JSON 文件。保存后成为新的材料草稿，重新总结会生成新会话，旧学习记录保留。
「浏览 B 站」提供关键词与主题搜索，搜索结果在新的 B 站页面打开；复制完整视频链接后可带回 App 读取字幕。此版本不是内嵌 B 站浏览器。「打开 B 站」直接打开官网。
「总结视频」在已有会话中展示保存的概要与精华；在材料页中使用当前字幕生成新总结，仅有视频链接时先尝试读取字幕。真实生成需要模型配置，不支持无字幕视频自动转写。

1. 先点击「体验演示」。演示使用固定示例，保存回答但不判断正确性；所有知识点保持未验证。
2. 在「模型设置」填入 Chat Completions 兼容服务的 API Base、实际支持的模型 ID 和密钥。API Base 包含 `/v1` 等接口前缀，程序追加 `/chat/completions`。本地无鉴权模型可不填密钥。
3. 粘贴完整 BV 视频链接（支持 `?p=2` 分 P）并尝试「读取字幕」；也可直接导入 TXT / SRT / VTT / Bilibili JSON 字幕。
4. 填写目标，生成学习地图。点击知识点的出处可查看原始字幕。
5. 一次回答一个问题，按需要使用「给提示」「直接讲解」「跳过」。结束后导出 Markdown 笔记，或从薄弱点继续。

学习数据在 `data/study.sqlite3`，可备份此文件。密钥只在服务进程内存中保存，不会写入学习数据，重启后需重新填写。
材料表单和未发送的回答会自动保存在当前浏览器的本地存储中；刷新会恢复上次打开的学习。回答草稿按会话与题目分别保存，不会串到下一题。浏览器清理网站数据会移除这些草稿，已经提交的学习记录仍在数据库中。
学习页面支持「互动练习」「知识地图与原文」「专注答题」三种视图。窄窗口默认直接显示练习，旧对话可展开查看。点击出处弹出原文；链接有效且字幕带时间戳时，可跳转到视频对应片段。进度条仅统计已有迁移应用证据的知识点。
可选环境变量：`STUDY_API_BASE`、`STUDY_MODEL`、`STUDY_API_KEY`。不要把密钥写入源码或提交版本库。

## 视频读取边界

- 自动读取仅尝试 Bilibili 提供、当前可访问的字幕，不下载视频。
- 未提供字幕、登录限制、风控或接口变化时会报出缺口，不会用标题猜概要。
- 可选在启动前设置 `BILI_SESSDATA`，读取本人能访问的字幕。登录凭据仅用于 Bilibili API，不发送给模型或字幕 CDN。
- 短链接需要先在浏览器展开。无字幕视频目前需自行转写后导入；此版本未实现音频下载、ASR 或画面分析。
- 所有导入材料标为字幕范围，不能证明画面中的公式、图表和操作已被覆盖。
- 一次最多 55,000 字符；超出需要分章节导入，程序不会默默截断。

## 学习与数据

提示词位于 `prompts/coach.md`。应用把它与 JSON 输出约束结合使用，校验引用 ID、模型格式与学习状态更新。
引用 ID 校验能防止伪造段落编号，不能自动证明模型解释完全忠于原文；仍可点击出处核对。
默认学习状态：未验证 → 需要提示 / 可独立解释 → 可迁移应用。依赖提示的正确回答需要再次独立验证；跳过不能计为掌握。
学习结束时导出内容包括薄弱点、练习任务、对话和原始字幕，供下次继续使用。

真实模型模式会把字幕、学习目标和近期回答发送到配置的服务。请使用你愿意将这些内容提供给它的模型服务。
服务只监听 127.0.0.1，并检查 Host、Origin 和请求类型。所有模型输出以纯文本显示，不执行其中的 HTML。

## 验证

```powershell
python -m unittest discover -s tests -v
```

测试包括字幕解析、虚构引用拒绝、提示与掌握分离、失败时进度不变、模拟模型 API、来源与凭据分离、本机接口和学习导出。
真实模型/Bilibili 网络连接依赖配置与平台可用性，演示与本地模拟测试不能证明远程服务可访问。
